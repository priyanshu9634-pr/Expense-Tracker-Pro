# Expense Tracker Pro

A responsive expense tracking web application built using HTML, CSS, JavaScript and Chart.js.

## Features
- Add/Delete Transactions
- Income & Expense Tracking
- Category Management
- Search Transactions
- Dark Mode
- Local Storage
- Interactive Doughnut Chart

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
